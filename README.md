# Motivetto — informativa sulla privacy

Questo repository contiene **solo l'informativa sulla privacy** di Motivetto:
[`PRIVACY.md`](PRIVACY.md). Nessun codice, nessun APK, nessuna release.

Motivetto è un'app Android che trasforma la voce in pattern musicali. Funziona
interamente sul telefono: non ha un account, non ha un server e **non ha nemmeno il
permesso di rete**, quindi quello che registri non può uscire dal dispositivo.

## Perché sta qui, e perché resta pubblico

Google Play pretende che l'informativa stia a un indirizzo **raggiungibile da chiunque**,
senza login. Ma l'ospitalità gratuita non è il motivo per cui è su GitHub: il motivo è
che **la cronologia di questo file è pubblica**, quindi l'informativa non può essere
cambiata in silenzio. È scritto dentro l'informativa stessa, ed è l'unica cosa che la
distingue da una promessa a voce.

Per questo il repository **deve restare pubblico**. Renderlo privato darebbe un 404 a
Play e toglierebbe la verificabilità della cronologia.

Il codice dell'app sta altrove, in un repository privato.

# Motivetto — privacy policy

This repository holds **only the privacy policy** for Motivetto:
[`PRIVACY.md`](PRIVACY.md). No code, no APK, no releases.

Google Play requires the policy to live at an address anyone can reach without logging
in. The reason it is on GitHub is not free hosting: it is that **the history of this
file is public**, so the policy cannot be changed silently. That guarantee is written
inside the policy itself, and it is the only thing that separates it from a spoken
promise — which is why this repository has to stay public.
